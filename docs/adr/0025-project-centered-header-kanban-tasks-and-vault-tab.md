# ADR 0025 — Project-centered Header, Kanban Tasks board, and dedicated Vault tab

- **Status:** Accepted — 2026-10-23, `grill-with-docs` Q3–Q5; refined 2026-10-24, `grill-with-docs` Q1–Q4; the Owner chose all recommendations.
- **Amends:** [ADR 0009](0009-factory-surface-and-lane-config.md) §2 (Factory surface Header and Tasks view) and [ADR 0014](0014-private-vault-hydration-and-release-lab-companion.md) §1 (Private vault placement).

The persistent Factory surface Header is simplified around a prominent **Project Switcher** showing the active Project, seat status and open actions, missing-folder warnings, and Project reset and delete controls. The Project Switcher works across both the global screen and the workspace panel (allowing the Owner to switch to another Project or `All projects` from a workspace panel and return to the panel's workspace). Any Project entry with `missingRoot: true` exposes an inline two-step `Delete` control directly on the switcher row in addition to the selected-project purge banner, and selecting a missing-folder Project suppresses vacant-seat startup hints in favor of a clear missing-directory purge callout. Adding a Project synchronizes with Paseo's workspace registry and uses a native macOS folder picker (with recent workspace suggestions and greenfield Git bootstrap) instead of requiring manual path entry.

The five KPI stat tiles and the full-width Private vault bar are removed from the Header so they no longer crowd the navigation bar:
- **Tasks** becomes a responsive five-column Kanban board (`Queued`, `In Progress`, `Needs Attention`, `Ready to Accept`, `Accepted`) that adapts to container width and `layout.compact`: on horizontal viewports (`>= 640px`), all five columns maintain equal width regardless of whether zero, one, or all five columns contain tasks, and tasks inside every column stack vertically in a single column (`flexDirection: "column"`); on compact/workspace-panel viewports (`< 640px`), empty columns collapse into a compact stage summary strip above a single-column vertical stack without horizontal overflow. Cards are kept compact and scannable (header with Task ID and attempt status dots or lane badge, 1–2 line truncated description, plus an actionable blocker callout on `Needs Attention` or direct `Accept #n` button on `Ready to Accept`), while full telemetry pills (`Gate`, `Eye`, `Watch`, `Choke`, `Cost`), contract details, reports, and gate logs open on click in `TaskDetailModal`.
- **Vault** becomes a dedicated fifth tab on the Factory surface (alongside the Settings screen), giving GitHub onboarding, bidirectional sync, and key management a full view without competing with the tab bar.
